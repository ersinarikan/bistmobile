# SEO Uzmanı — Referans

## A. Teknik SEO (web)

| Alan | Kontrol |
|------|---------|
| Index | robots.txt, noindex yanlışlıkla, sitemap.xml güncelliği |
| URL | Kısa, tutarlı, trailing slash politikası, 301 zinciri yok |
| Canonical | Tek tercih URL; parametreli kopyalar |
| Meta | Unique title/description; hisse sayfalarında şablon + sembol |
| Heading | Tek H1; mantıklı H2/H3 |
| Structured data | Organization, WebSite, FinancialProduct/Article uygunsa; Rich Results test |
| Performance | LCP/INP/CLS; kritik CSS; görsel boyut |
| Mobile | Responsive; tap target; viewport |
| Güven | HTTPS; karışık içerik yok |

## B. İçerik SEO (finans)

- Kullanıcı niyeti: bilgilendirme vs işlem — net ayır.
- “Yatırım tavsiyesi değildir” ve metodoloji linkleri korunur.
- Thin content / tarama kopyası üretme; özgün özet + kaynak.
- Dahili link: BIST 30/100, hisse, metodoloji, blog kümesi.

## C. ASO (App Store + Google Play)

**Ortak**
- Uygulama adı / alt başlık: marka + birincil fayda (LOTLOT / BIST analiz).
- Kısa açıklama (Play) / subtitle (iOS): keyword + fayda.
- Uzun açıklama: madde işaretleri, ilk 3 satır kritik.
- Ekran görüntüleri: gerçek UI; abartılı getiri iddiası yok.
- Gizlilik etiketleri / Data safety formu doğru (JWT, analytics, push).

**Keyword**
- Birincil: BIST, hisse analiz, borsa (lokal dil TR).
- Rakip isim spam’i yok.
- Yerelleştirme: TR öncelik; EN ayrı metadata.

**Dönüşüm**
- İkon (launcher) tutarlılığı; ilk screenshot value prop.
- Rating prompt zamanlaması (kritik akış sonrası, spam değil).

## D. Mobil ↔ web köprü

- Universal Links / App Links: `lotlot.net` path’leri ile hizalı.
- Paylaşılan hisse URL’si uygulamada doğru ekranı açmalı.
- Web’de PWA ikon/manifest ile mobil marka tutarlı.

## E. Ölçüm KPI

- Organik tıklama / gösterim (Search Console).
- Mağaza: impressyon → sayfa görüntüleme → yükleme.
- Deep link açılma oranı; 404 / fallback oranı.
- Core Web Vitals (web).

## F. Öncelik örneği (LOTLOT)

1. Store listing + gizlilik doğruluğu (ASO / compliance).
2. Deep link hisse sayfaları.
3. Web hisse SSR meta/schema (BIST).
4. İçerik kümesi / dahili link.
5. Performans iyileştirmeleri.
